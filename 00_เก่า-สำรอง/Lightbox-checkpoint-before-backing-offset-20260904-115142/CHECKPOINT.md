# Lightbox Maker — ก่อนทดลองแผ่นรองหลัง +Offset

สร้างเมื่อ 2026-09-04 11:51:42 (Asia/Bangkok) ตามคำขอผู้ใช้ให้เก็บจุดย้อนกลับก่อนทดลองขั้นต่อไป

## สถานะที่เก็บ

- รูปแบบงานเริ่มต้น: พิมพ์แยกฝาหน้าถอดเปลี่ยนได้
- 5D ขอบโค้งมนและ 5D Chamfer แยกเป็นคนละรูปแบบงาน
- พิมพ์เฉพาะตัวกล่อง: เผื่อสวมแผ่น 0.1–0.3 มม./ข้าง ค่าเริ่มต้น 0.2 มม. ปรับทีละ 0.05 มม.
- เส้นตัดอะครีลิค/พลาสวูดร่นตามความหนาผนังกรอบ + เผื่อสวม ไม่ลดความหนาผนังกรอบ
- เมนูส่งออกโหมดตัวกล่องแสดง “3MF + DXF + SVG (แนะนำ)” และส่ง ZIP เส้นตัดแยก
- ยังไม่มีแผ่นรองหลังใส +Offset, พรีวิวแผ่นรอง, การนับชิ้นที่เชื่อม หรือไฟล์เส้นตัดแผ่นรอง
- ชุดทดสอบ Lightbox ล่าสุดก่อน checkpoint ผ่าน 15 รายการ

## การย้อนกลับ

เมื่อผู้ใช้ขอย้อนกลับ ให้สำรองงานล่าสุดก่อน แล้วคืนเฉพาะสามไฟล์ข้างต้นไปยังเส้นทางเดิมใน repository ตรวจ MD5 และรันทดสอบ Lightbox อีกครั้ง ห้าม reset ทั้ง repository เพราะมีงาน Booth Editor ที่ไม่เกี่ยวข้อง

จุดนี้เก็บซอร์สโค้ดและเทสต์ ไม่ได้เก็บสถานะโปรเจกต์หรือภาพอัปโหลดที่ยังไม่ได้บันทึกในแท็บเบราว์เซอร์
